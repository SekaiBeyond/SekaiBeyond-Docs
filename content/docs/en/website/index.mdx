These pages are for people working on [SekaiBeyond-Web](https://github.com/SekaiBeyond/SekaiBeyond-Web), the source of the official Sekai Beyond website. Its README covers cloning, installing and the npm scripts; how to send a change is in its [CONTRIBUTING.md](https://github.com/SekaiBeyond/SekaiBeyond-Web/blob/main/CONTRIBUTING.md).

## Tech stack

| Technology | Purpose |
|---|---|
| [React](https://react.dev/) | UI Framework |
| [React Router](https://reactrouter.com/) | Framework & Routing |
| [TypeScript](https://www.typescriptlang.org/) | Type Safety |
| [Vite](https://vitejs.dev/) | Build Tool |
| [Firebase](https://firebase.google.com/) | Auth, Firestore, Cloud Storage, Cloud Functions |
