<Endpoint method="GET" path="/v1/events" scope="events:read" />

<ApiPage operation="listEvents">

Returns the events the caller may see:

- **With a server API key:** every event (unarchived and archived, free and paid, published or not), or the events the key is held to. Filter on the [Event](./event.mdx) flags (`archived`, `published`, `paid`, `onSale`, `deleteAt`) for what you need.
- **With a person's sign-in:** the events that person can see on the site—every archived event, plus unarchived events that are `published: true`, or unpublished ones if the person is staff or that event's own staff.

## Parameters

None.

## Returns

**200** with an object holding the events:

<Params>
<Param name="events" type="Event[]">
Unarchived events first, soonest first, then archived ones, latest first. That's the order the site lists them in. Every field is listed in [The Event object](./event.mdx).
</Param>
</Params>

## Errors

Only the ones every endpoint can return: see [Errors](./errors.mdx).

</ApiPage>
