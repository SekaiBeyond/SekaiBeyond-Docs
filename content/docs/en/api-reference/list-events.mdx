<Endpoint method="GET" path="/v1/events" scope="events:read" />

<ApiPage operation="listEvents">

Returns every event (unarchived and archived, free and paid, published or not), or the events the key is held to. Filter on the [Event](./event.mdx) flags (`archived`, `published`, `paid`, `onSale`, `deleteAt`) for what you need.

## Parameters

None.

## Returns

**200** with an object holding the events:

<Params>
<Param name="events" type="Event[]">
Unarchived events first, soonest first, then archived ones, latest first. That's the order the site lists them in. Every field is listed in [The Event object](./event.mdx).
</Param>
</Params>

## Errors

| Status | Code | When |
|---|---|---|
| 403 | `api-key-required` | Called with a person's sign-in instead of a server API key. |

Plus the ones every endpoint can return: see [Errors](./errors.mdx).

</ApiPage>
