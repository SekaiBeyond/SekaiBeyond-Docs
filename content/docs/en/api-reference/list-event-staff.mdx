<Endpoint method="GET" path="/v1/events/{eventId}/staff" scope="event-staff:read" />

<ApiPage operation="listEventStaff">

Returns the people assigned as event staff for an event, archived or not. Needs a server API key with `event-staff:read`, held to that event or to none. That check runs before the event is looked up, so a key held to other events can't tell which event IDs exist. Who in your app may see the list is up to your app.

## Path parameters

<Params>
<Param name="eventId" type="string" required>
The event's ID, from [List events](./list-events.mdx).
</Param>
</Params>

## Returns

**200** with an object holding the event's ID and its staff:

<Params>
<Param name="eventId" type="string">
The event's ID.
</Param>
<Param name="staff" type="Person[]">
The event's staff, sorted by highest group first, then by `displayName`. Every field is listed in [The Person object](./person.mdx).
</Param>
</Params>

## Errors

| Status | Code | When |
|---|---|---|
| 403 | `api-key-required` | Called with a person's sign-in instead of a server API key. |
| 403 | `event-not-allowed` | The key is held to other events. |
| 404 | `event-not-found` | No event has this ID. |

Plus the ones every endpoint can return: see [Errors](./errors.mdx).

</ApiPage>
