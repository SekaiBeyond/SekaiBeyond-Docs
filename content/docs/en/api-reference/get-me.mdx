<Endpoint method="GET" path="/v1/me" />

<ApiPage operation="getMe">

Returns the person signed in to the app, as they are now on the site. Needs a person's sign-in (see [Sign in with Sekai Beyond](../ticket-api/sign-in.mdx)), and no scope. With `event-staff:read`, it also lists the events they're event staff for.

Use this to read the person's current `group`, `displayName`, `photoURL`, `title`, `titleCn` and event-staff events. Their token's `group` and `eventStaff` claims can be up to an hour behind.

## Parameters

None.

## Returns

**200** with the [Person](./person.mdx), and, only if the app has `event-staff:read`:

<Params>
<Param name="eventStaffEvents" type="string[]">
The IDs of every event the person is event staff for, archived ones included, in no particular order, or `[]`. Unlike the token's `eventStaff` claim, it's never cut short.
</Param>
</Params>

## Errors

| Status | Code | When |
|---|---|---|
| 403 | `sign-in-required` | Called with a server API key instead of a person's sign-in. |

Plus the ones every endpoint can return: see [Errors](./errors.mdx).

</ApiPage>
