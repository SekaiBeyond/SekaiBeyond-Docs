---
title: 获取绑定
description: 你的应用的用户绑定了哪个账号（如果有）。
full: true
---

<Endpoint method="GET" path="/v1/account-links/{appUserId}" scope="accounts:link" />

<ApiPage operation="getAccountLink">

返回你的应用的用户所绑定的账号。用户随时可以在官网解绑，而官网不会通知你的应用，所以请在用户打开展示绑定的页面时调用它，并把 `404 not-linked` 视为未绑定。

## 路径参数

<Params>
<Param name="appUserId" type="string" required>
你的应用为该用户分配的 ID。
</Param>
</Params>

## 返回

**200**，返回 [AccountLink](./account-link.mdx)。其中的名称和头像是账号当前的名称和头像。

## 错误

| 状态码 | 错误码 | 何时出现 |
|---|---|---|
| 403 | `no-seller` | 密钥没有销售方 ID。 |
| 404 | `not-linked` | 该用户没有绑定账号：从未绑定、已从任一方解绑，或账号已被删除。 |

另外还有所有端点都可能返回的错误，见[错误](./errors.mdx)。

</ApiPage>
