---
title: 删除绑定
description: 解除你的应用的用户与其账号的绑定。
full: true
---

<Endpoint method="DELETE" path="/v1/account-links/{appUserId}" scope="accounts:link" />

<ApiPage operation="deleteAccountLink">

解除你的应用的用户与其账号的绑定，和账号持有者在官网设置中解绑效果相同。已经归到账号下的订单仍归该账号，因为它们是为该账号购买的；此后的新订单则不再归它。解绑会记录在官网的「操作记录」中。

## 路径参数

<Params>
<Param name="appUserId" type="string" required>
你的应用为该用户分配的 ID。
</Param>
</Params>

## 返回

**200**，包含：

<Params>
<Param name="appUserId" type="string">
该用户，即发送的值。
</Param>
<Param name="unlinked" type="boolean">
始终为 `true`。
</Param>
</Params>

## 错误

| 状态码 | 错误码 | 何时出现 |
|---|---|---|
| 403 | `no-seller` | 密钥没有销售方 ID。 |
| 404 | `not-linked` | 该用户没有绑定，例如已经在官网解绑。视为已完成即可。 |

另外还有所有端点都可能返回的错误，见[错误](./errors.mdx)。

</ApiPage>
