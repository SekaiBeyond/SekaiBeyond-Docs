---
title: 获取个人主页
description: 已绑定账号的徽章、通行证和活动，与账号持有者自己看到的一样。
full: true
---

<Endpoint method="GET" path="/v1/account-links/{appUserId}/profile" scope="accounts:link" />

<ApiPage operation="getAccountProfile">

返回你的应用的用户所绑定账号的个人主页，与账号持有者在自己的个人主页上看到的一样：身份、会员、徽章、通行证和参加过的活动，名称和图片都已查好。

<Callout type="warn" title="只展示给该用户本人。">
  它不受持有者为他人设置的隐私开关影响，和持有者自己的个人主页一样。
</Callout>

每次调用都会重新读取，所以请缓存几分钟，而不是每次打开页面都获取。

## 路径参数

<Params>
<Param name="appUserId" type="string" required>
你的应用为该用户分配的 ID。
</Param>
</Params>

## 返回

**200**，返回 [AccountProfile](./account-profile.mdx)。

## 错误

| 状态码 | 错误码 | 何时出现 |
|---|---|---|
| 403 | `no-seller` | 密钥没有销售方 ID。 |
| 404 | `not-linked` | 该用户没有绑定账号。 |

另外还有所有端点都可能返回的错误，见[错误](./errors.mdx)。

</ApiPage>
