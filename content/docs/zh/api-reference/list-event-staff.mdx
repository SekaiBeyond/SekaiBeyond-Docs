---
title: 列出活动工作人员
description: 某个活动的工作人员名单，无论是否已归档。
full: true
---

<Endpoint method="GET" path="/v1/events/{eventId}/staff" scope="event-staff:read" />

<ApiPage operation="listEventStaff">

返回被指派为某个活动的工作人员的用户列表，无论该活动是否已归档。需要具备 `event-staff:read` 的服务器 API 密钥，且该密钥限定于此活动或不限活动。该检查在查找活动之前进行，因此限定于其他活动的密钥无法借此探测哪些活动 ID 存在。你的应用中谁能查看这份名单，由你的应用决定。

## 路径参数

<Params>
<Param name="eventId" type="string" required>
活动 ID，来自[列出活动](./list-events.mdx)。
</Param>
</Params>

## 返回

**200**，返回一个包含活动 ID 及其工作人员的对象：

<Params>
<Param name="eventId" type="string">
活动 ID。
</Param>
<Param name="staff" type="Person[]">
该活动的工作人员，先按最高组别排序，再按 `displayName` 排序。所有字段见 [Person 对象](./person.mdx)。
</Param>
</Params>

## 错误

| 状态码 | 错误码 | 何时出现 |
|---|---|---|
| 403 | `api-key-required` | 使用了用户的登录凭证（而非服务器 API 密钥）发起调用。 |
| 403 | `event-not-allowed` | 密钥限定于其他活动。 |
| 404 | `event-not-found` | 没有这个 ID 的活动。 |

以及所有端点都可能返回的错误，见[错误](./errors.mdx)。

</ApiPage>
