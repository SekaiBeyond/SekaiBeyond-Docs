---
title: 获取活动
description: 获取单个活动，无论是否已归档，例如在收款前再确认一次。
full: true
---

<Endpoint method="GET" path="/v1/events/{eventId}" scope="events:read" />

<ApiPage operation="getEvent">

返回单个活动，无论是否已归档。在收款前调用它，确认 `onSale` 仍为 `true`。

## 路径参数

<Params>
<Param name="eventId" type="string" required>
活动 ID，来自[列出活动](./list-events.mdx)。
</Param>
</Params>

## 返回

**200**，返回 [Event](./event.mdx)。

## 错误

| 状态码 | 错误码 | 何时出现 |
|---|---|---|
| 403 | `event-not-allowed` | 密钥限定于其他活动。 |
| 404 | `event-not-found` | 没有这个 ID 的活动。 |

以及所有端点都可能返回的错误，见[错误](./errors.mdx)。

</ApiPage>
