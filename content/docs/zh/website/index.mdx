这些页面面向参与开发 [SekaiBeyond-Web](https://github.com/SekaiBeyond/SekaiBeyond-Web) 的人，它是 Sekai Beyond 官网的源代码。克隆、安装和 npm 脚本见它的 README；如何提交修改见它的 [CONTRIBUTING.md](https://github.com/SekaiBeyond/SekaiBeyond-Web/blob/main/CONTRIBUTING.md)。

## 技术栈

| 技术 | 用途 |
|---|---|
| [React](https://react.dev/) | UI 框架 |
| [React Router](https://reactrouter.com/) | 框架与路由 |
| [TypeScript](https://www.typescriptlang.org/) | 类型安全 |
| [Vite](https://vitejs.dev/) | 构建工具 |
| [Firebase](https://firebase.google.com/) | Auth、Firestore、Cloud Storage、Cloud Functions |
